# Security Policy

## Reporting a Vulnerability

Security is paramount for an authentication library. If you discover a security vulnerability in `go-auth`, please report it responsibly.

**Do not open a public issue.**

Please report security vulnerabilities by email:
- **Email**: mdsufiyanbari866@gmail.com
- **Response Time**: TBD (initial acknowledgment expected within 48 business hours)

Please include the following details in your report:
- Type of issue (e.g. CSRF, session fixation, timing attack, token leakage)
- Detailed steps to reproduce or proof-of-concept
- Affected versions or components
- Potential impact

We will coordinate a fix and advisory before public disclosure.
