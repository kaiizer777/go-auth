# Deferred Features (Not in v1)

The following capabilities are explicitly deferred from the v1 scope to preserve architectural clarity and deliver a rock-solid, production-grade foundation:

- **Passkeys / WebAuthn**: FIDO2 / WebAuthn passwordless authentication (planned for v2+).
- **2FA / TOTP**: Time-based one-time password two-factor authentication and backup codes (planned for v2+).
- **Magic Links**: Passwordless email magic link sign-in flows (planned for v2+).
- **SAML / SCIM**: Enterprise SSO and directory sync protocols (planned for v2+).
- **Multi-tenant / Organizations**: Native multi-tenant isolation, organization hierarchies, and role delegations (planned for v2+).
- **Additional DB Adapters**: Non-relational or alternative database adapters such as MongoDB, DynamoDB, or Redis-native session stores (planned for v2+).
